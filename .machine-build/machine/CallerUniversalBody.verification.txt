WHAT CHANGED (the body rewrite)
-------------------------------
`univRowPass` was `x.n` stores per round at `x.c + t*n + u`. It is now ONE
guarded store:

    univRowPass := .ite (v Rt =' k 0) (.store (v Out) (v Tmp)) .skip

Write set = {x.c}, for EVERY instance. `{x.c} ⊆ [x.c, x.c + n^2)` for every
n >= 1, so the certified stage post (SameOutside3 at sb/bb/mb) and the final
KeptBut hold unconditionally and `hregion : mpRounds W <= n` is NEVER NEEDED.

WHY THE ROW WAS NEVER MATHEMATICS. The only cell any landed conclusion
consumes is the product's head `x.c`: `CallerRun.MinPlusIdentity` takes the
round-0 fold at `bracketCell x 0 0 = x.c` as its hypothesis and concludes
EVERY cell's `minPlusEntry`, and `mpTask.Post`'s Seg half follows from that
premise via `seg_of_entries`. Rounds t >= 1 deliver the fold seeded at ROW t's
head — a different value — so the store is guarded to `t = 0`.

THE "REGISTER ACCUMULATION", STATED AS THE EQUIVALENCE IT IS. Carrying the
fold in a register and storing once after the loop is the same program up to
the observation that nothing between round 0 and the loop's exit reads or
writes the head. Disclosed at the def, not silently substituted.
