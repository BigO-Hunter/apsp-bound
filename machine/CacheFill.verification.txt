WHAT CHANGED AND WHY (the finding, not the preference). `cacheTask.Post`
carried `Kept μ μ' fr` — "nothing below the free pointer changes" — while
`Pre` places the WHOLE rows region below that pointer
(`Pre x μ fr := x.rb + x.P * x.I ≤ fr`). For the cache's non-degenerate case
(`1 ≤ P`, `1 ≤ I`, the only case the universal body consumes) the two
conjuncts are jointly satisfiable ONLY when the rows region already holds
`rows`. So the old post ENTAILED

    rows p i = μ (rb + p·I + i)                                     (*)

at the ENTRY memory — i.e. exactly the raw FILL-1 memory image the cache was
supposed to PRODUCE. Consequence, and the reason this is a repair and not a
restatement: a `Light.Solves cacheTask …` premise stated with the old frame
does not put the image behind the cache boundary, it puts the image INSIDE
the premise. Route (c) — "call the cache procedure before `univPrologue` and
the rows conjunct becomes a theorem" — would then have been a RENAMING of the
premise, not a reduction of it.

The receipt for (*) is `image_of_kept_post`, kept in the file: it is stated
about the OLD shape and is true; nothing below depends on it.

The repaired frame is `KeptBut μ μ' fr x.rb (x.P * x.I)`: everything below the
free pointer EXCEPT the rows region the task is defined to fill. This is the
same class of finding as the bundle's refuted flag conjunct
(`CallerFill1Measure.hflag_shape_false`, repaired at 06a523e) — a premise that
looks like a boundary and is in fact the thing it was meant to produce.

DOWNSTREAM EFFECT, stated exactly:
- `cacheReads_of_solves` now delivers `KeptBut μ σ'.mem fr x.rb (x.P*x.I)`
  (it delivered `Kept` before). Nothing else about it moved.
- `reads_persist` is RESTATED and STRENGTHENED: it consumed `Kept` plus an
  entry-memory rows image (`hRR : ∀ p < P, ∀ i < I, μ (rb+p·I+i) = rows p i`)
  and produced all three read families at `μ'`. It now consumes `KeptBut` and

  the active-bit and remaining-flag premises (which lie outside the rows
  region by `InOrder`) come from the frame. That asymmetry is the whole
  content of the repair — the image is now produced, not assumed.
  The unused `{h : ℕ}` binder was dropped with the restatement.
